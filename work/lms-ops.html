( overview )

2년 반 동안 80여 건의 종합반 프로모션 페이지와 배너를 디자인하고 퍼블리싱했습니다.
프로모션 외에도 서비스 화면의 UI 수정과 추가를 함께 담당했습니다.

( 01 )

반복 제작을 고려한 프로모션 디자인

운영 초기에는 프로모션마다 페이지를 새로 제작했습니다.
작업이 반복되면서 공통 영역은 재활용하고 주요 프로모션은 키비주얼 제작에 집중했습니다.

키비주얼은 시즌과 상품 성격에 맞춰 새로 제작했습니다. 강의정보와 수강신청 영역은 레이아웃을 고정하고 컬러만 바꿔 적용했습니다.

( 02 )

수정이 쉬운 프로모션 퍼블리싱 구조

변경이 적은 비주얼 영역은 이미지로, 상품명과 가격처럼 자주 바뀌는 정보는 HTML로 분리해 필요한 부분만 수정할 수 있도록 했습니다.
수정 사항은 직접 코드를 고쳐 Git에 올리고 개발자 확인 후 배포했습니다.

상품 블록(.prm-pkgitem)만 추가하거나 빼면 상품 수가 달라도 같은 구조를 그대로 쓸 수 있도록 작성했습니다.

( 03 )

프로모션 키비주얼을 활용한 배너 재구성

프로모션 키비주얼의 타이포그래피와 그래픽 요소를 유지하면서 메인·팝업·외부 채널 배너 규격에 맞게 레이아웃을 재구성했습니다.
지면마다 상품명과 핵심 메시지가 잘 보이도록 요소의 크기와 배치를 조정했습니다.

( 04 )

운영하며 바뀐 탐색과 홍보 구조

서비스 운영 중 학원의 요청과 상품 구성 변화에 맞춰, 헤더와 메인, 배너 영역을 단계적으로 수정했습니다.

상품이 늘어나도 찾기 쉬운 헤더 구조로

상품 종류와 수가 늘어나는 데 맞춰 헤더 메뉴를 단계적으로 바꿨습니다.

메인 배너가 내려간 뒤에도 상품을 찾을 수 있도록 종합반 상품을 메뉴에 노출했습니다. 이후 상품이 늘어나 LNB가 길어지자, 상품 구분에 따라 열을 나누는 구조를 제안해 반영했습니다.

콘텐츠를 늘린 메인 화면

약 1년 운영 후 메인에 더 많은 정보를 담아 달라는 요청에 맞춰 개편했습니다.

초기에는 기존 강의 사이트와 차별화해 달라는 요청에 따라 홍보 배너와 메뉴 버튼 중심으로 구성했습니다. 개편하면서 교재, 공지, 후기와 시험별 종합반·단과반 배너 영역을 추가했습니다.

홍보 영역을 늘린 띠배너

메인 배너 외에도 상품을 홍보할 영역이 필요하다는 요청에 맞춰 일부 화면에 띠배너를 추가했습니다.

기존 레이아웃을 크게 바꾸지 않고, 각 화면의 주요 목적을 해치지 않는 위치에 배치했습니다.

( 05 )

회고

한 가지 방식만 검토했던 띠배너 규격

프로모션 페이지와 메인 배너는 PC와 모바일 두 가지 규격으로 제작했고, 메인 배너는 태블릿 구간부터 모바일 배너 양옆에 이전·다음 배너가 보이도록 했습니다. 운영 중 일부 페이지에 띠배너가 추가되었는데, 같은 방식을 쓰면 화면이 산만해질 것 같았습니다. 그래서 태블릿용 이미지를 따로 만들지 않고, 배너 너비는 태블릿에 맞추되 주요 콘텐츠는 모바일 기준 너비 안에 배치했습니다. 돌아보면 배너를 한 장씩 보여주는 방식 안에서만 답을 찾았던 것 같습니다. 다시 작업한다면 태블릿에서는 배너를 두 장씩 나란히 보여주는 방식도 함께 검토할 것 같습니다.

사용자 행동을 확인하기 어려웠던 화면 수정

운영 중 상품 판매가 저조하면 프로모션 페이지의 할인 정보를 강조하거나 상품 노출을 늘려 달라는 요청이 있었습니다. 요청의 목적을 확인해 다른 방식을 제안하기도 했지만, 유입이 적은 것인지 사용자가 가격과 수강 신청 영역까지 도달하지 못하는 것인지 확인할 데이터가 없어 아쉬웠습니다. 이를 계기로 퇴사 후 마케팅 디자인 워크숍을 수강하며 성과 지표와 분석 도구, 히트맵으로 사용자 행동을 살펴보는 방법을 접했습니다. 다시 비슷한 상황이 온다면 해결하려는 문제를 먼저 정리하고, 가능하다면 사용자 행동 데이터를 살펴본 뒤 개선 방향을 제안할 것 같습니다.
